Practice Scenarios

Five practical investigations

Work them in order. Each builds on the detection logic and evidence vocabulary of the one before it. Your answers must be supported by data you find in the SIEM.

Scenario 01 Easy

Brute Force Investigation

A burst of failed SSH logons against the web server. Establish the source IP, the accounts attacked, the exact time window, and the corroborating firewall evidence.

Rule: brute_force Start Investigation
Scenario 02 Medium

Successful Login After Brute Force

The same failure pattern — but this time a login succeeded. Correlate the failures to the success and explain why the severity escalated to critical.

Rule: successful_brute_force Start Investigation
Scenario 03 Medium

Suspicious Post-Login Process Execution

A Windows account authenticated, then launched a command shell seconds later. Measure the gap, read the command line, and explain why it is dangerous.

Rule: suspicious_process_post_login Start Investigation
Scenario 04 Hard

Linux Privilege Escalation & Reverse Shell

A Linux account logged in over SSH, then used sudo to start an interactive root shell. Separate this from the legitimate sudo activity on the same host.

Event: privilege_escalation Start Investigation
Scenario 05 Hard

Multi-Event SOC Investigation

The full incident. Build the complete timeline across every host, rank the findings by severity, and write the incident conclusion a SOC would escalate.
